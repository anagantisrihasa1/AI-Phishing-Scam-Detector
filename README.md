# 🛡️ AI Phishing & Message Scam Detector

## Overview

AI Phishing & Message Scam Detector is a Python-based web application built using Streamlit. The system analyzes messages, emails, SMS, and chat text to identify potential phishing attempts and scam content.

The application detects suspicious keywords and alerts users about possible online threats, helping them stay safe from cyber scams.

---

## Objectives

- Detect phishing messages.
- Identify scam-related keywords.
- Warn users about suspicious content.
- Improve cybersecurity awareness.
- Provide a simple and interactive interface.

```bash

```

---

## Working

1. User enters a message.
2. The system scans the text.
3. Suspicious keywords are detected.
4. Risk level is calculated.
5. Results are displayed to the user.
